# MartX — сайт-визитка

Одностраничный лендинг для IT-проекта **MartX**: сборка, апгрейд и настройка ПК.

- **Стек:** HTML5 + CSS (без препроцессоров) + ES-модули JS.
- **Хостинг:** GitHub Pages.
- **Стиль:** Tech/Dark · акцент `#FF6B00`.

## Структура

```text
martx/
├── index.html
├── css/           — стили по компонентам
├── js/
│   ├── main.js    — точка входа

├── print/         — визитки для печати

    ├── favicon.svg
    └── img/       — плейсхолдеры портфолио
